SETUP GUIDE

Connect
WhatsApp.

About ten minutes with Meta's free test number. ReplyDock answers messages people send to your business number. It does not start conversations, so the final test is you messaging the bot from your own phone.

  1. STEP 1

    Create a Meta app with WhatsApp

    Open developers.facebook.com/apps → Create app → choose the business type → add the WhatsApp product. Meta gives you a free test business number.

  2. STEP 2

    Allow your phone as a recipient

    In WhatsApp → API Setup, under To, add your own phone number with country code (for example +60123456789). Meta sends a code to that phone over WhatsApp; enter it to confirm. Test numbers can only message recipients approved this way.

  3. STEP 3

    Copy the credentials into .env

    From API Setup copy the temporary access token and the Phone number ID. From App settings → Basic copy the App secret. Pick any string as the verify token. Put them in .env next to server.py and restart ReplyDock:

    WHATSAPP_ACCESS_TOKEN=EAAG...
WHATSAPP_PHONE_NUMBER_ID=1234567890
WHATSAPP_APP_SECRET=abc123...
WHATSAPP_VERIFY_TOKEN=pick-any-string

    The temporary token expires after about 24 hours. For a long-running setup, create a System User token in Meta Business Settings.

  4. STEP 4

    Send a test message

    This sends Meta's hello_world template to the number you approved in step 2. Business-started messages must use a template, so this checks the token and phone number ID without needing a webhook yet.

  5. STEP 5

    Give ReplyDock a public HTTPS address

    Meta can only deliver to a public HTTPS URL. For testing, a tunnel is easiest:

    cloudflared tunnel --url http://localhost:8080

    It prints an address like https://random-words.trycloudflare.com. Paste it here to build your webhook URL:

    Callback URL:

    For a permanent setup, run ReplyDock behind a reverse proxy with HTTPS and set REPLYDOCK_HOST=0.0.0.0 and REPLYDOCK_ADMIN_TOKEN.

  6. STEP 6

    Register the webhook in Meta

    In WhatsApp → Configuration → Webhook → Edit: paste the callback URL from step 5 and the same WHATSAPP_VERIFY_TOKEN, then Verify and save. Meta checks it immediately; if it fails, confirm ReplyDock is running and the tunnel is up. Then under Webhook fields, Subscribe to messages.

  7. STEP 7

    Message the bot

    From your phone, send hello to the test business number. ReplyDock should answer within a few seconds using the matching rule. Incoming WhatsApp messages appear below; this list refreshes automatically.

TROUBLESHOOTING

If nothing happens

  • Nothing appears in step 7. The webhook isn't reaching ReplyDock. Check that it was verified, that messages is subscribed, and that the tunnel is still running (a quick tunnel gets a new URL every time it restarts).
  • Message appears with status no match. No enabled rule matches the text. Add or enable one on the dashboard.
  • Status failed: ... 190. The access token is invalid or expired. Copy a new one and restart.
  • Status failed: ... 131030. The recipient isn't in the allowed list (step 2).
  • Webhook returns 401. WHATSAPP_APP_SECRET doesn't match the app that sends the webhooks.
